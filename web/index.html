Leave guard D6/D7, BOOT, RESET and debug pads unconnected. GPIO numbers vary by model.

          

        

        
03 / Wired UART test · two USB adapters
          
Connect two 3.3 V USB-to-UART adapters to this guard. Remove the radio and flight controller from the fixture. Power the guard through its USB; leave adapter power pins disconnected.

          
Adapter TX → D9 · RX ← D8 · GND → GND
Adapter TX → D5 · RX ← D4 · GND → GND

          

          
Six-second test: report forwarding, return heartbeat, forbidden parameter requests and bad CRC. Full-rate traffic, resets, power faults and FC routing still require hardware acceptance.

        

        
XIAO compatibility & porting candidates
