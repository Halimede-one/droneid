# OpenDroneID Core C

Source: https://github.com/opendroneid/opendroneid-core-c

Pinned revision: `849c03adbe0cdd68997a462fafab397edcfe53f3`.

License: Apache-2.0. `opendroneid.h` and `LICENSE` are unmodified upstream files.
Local changes: `CMakeLists.txt` integrates ESP-IDF; two timestamp arguments in
the unused `printAuth_data` / `printSystem_data` debug helpers are cast to
`unsigned int` to match their `%u` formats under the ESP-IDF v6.1 toolchain.
The wire encoder/decoder is unchanged.
Only the upstream core message codec is compiled; upstream Wi-Fi and MAVLink
adapters are not included. The project's `components/rid/rid_wifi.c` implements
bounded Wi-Fi framing, with tests using fixtures generated by the pinned
upstream Wi-Fi builders. Vendoring makes firmware and host tests build without
a network fetch.
